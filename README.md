# For Priti — A Birthday Written in the Stars ♡

A self-contained, mobile-friendly birthday microsite made by Jeffrin for Priti. It includes the opening gift-and-whistle sequence, India-time birthday countdown, photo and video memories, birthday letters, cake celebration, creative studio, selfie booth, final surprise, and a new one-minute mini-game.

## Run locally

Keep `index.html`, `style.css`, `script.js`, and the `assets/` folder together. Open `index.html` in a browser or use VS Code Live Server. The website uses plain HTML, CSS and JavaScript; there are no build steps or package dependencies.

## Add the personal media

Use the filenames listed in `assets/photos/README.txt`, `assets/videos/README.txt`, and `assets/music/README.txt`. The current project contains the original visual artwork and graceful placeholders, but not Priti's private photographs, videos or chosen birthday song. Add only media you have permission to share.

## The one-minute game

Open **little game** in the navigation and press **start the little game**. Catch golden stars (+1), collect bonus hearts (+3), and avoid sleepy clouds (-2). Every fifth good catch gives a +2 combo bonus. Reach 26 points before the 60-second timer ends. Pause/resume is supported, and the personal-best score is stored locally in that browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the project files and folders (not the ZIP itself).
2. In the repository, open **Settings → Pages**.
3. Under the build/deployment settings, choose **Deploy from a branch**, select your publishing branch (usually `main`) and the repository root (`/`).
4. Save, then open the Pages URL shown by GitHub after deployment.

The site is static, so no server, API key or database is required. Camera access for the selfie booth requires HTTPS; GitHub Pages provides HTTPS.

## Notes

- The countdown follows `Asia/Kolkata` and targets November 26.
- The mini-game is optional; it does not block the existing four-chapter final surprise.
- Best score is saved only in the visitor's own browser and is not uploaded anywhere.
- The artwork under `assets/images/` is original procedural artwork created for this project.

## Size and privacy

The current extracted project is approximately 5 MB, including its original celestial artwork and the preserved source backups. The HTML, CSS and JavaScript themselves remain lean; the artwork is what brings the project close to the requested size. The personal photos, videos and music are not included yet, so adding them will increase the total size.

Before publishing, make sure Priti is comfortable with the photos/videos being online and that everyone shown has agreed to being included. GitHub Pages sites are publicly accessible on the internet, so do not upload anything private or sensitive.
