PRITI'S BIRTHDAY WEBSITE — LEGENDARY EDITION
============================================

START HERE
----------
1. Extract the ZIP folder.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in a modern browser, or use VS Code Live Server.
4. Add the real photos, videos and birthday soundtrack using the exact names in the asset README files.

WHAT'S INCLUDED
---------------
- India Standard Time countdown to November 26.
- Animated gift → whistle → fireworks opening sequence and floating balloon garden.
- Photo memories, three video moments, birthday letter, wishes, cake ceremony, drawing studio,
  personal-letter area, selfie booth, final message and the existing secret-star surprise.
- NEW: “Catch the Starlight”, a replayable 60-second mini-game. Collect golden stars (+1), bonus
  hearts (+3), avoid sleepy clouds (-2), and build a five-catch combo for +2 bonus points.
  Reach 26 points before the timer runs out. It includes pause/resume, a personal-best score,
  mobile-friendly touch targets, eight rotating celestial skies and a win celebration.
- Original, high-resolution celestial artwork used by the new game.

COUNTDOWN
---------
The countdown uses Asia/Kolkata time and targets midnight at the start of November 26. It rolls
forward to the next November 26 after the birthday.

PERSONAL MEDIA
--------------
The supplied files did not include Priti's photographs, videos or chosen music. The assets
folders contain exact filename instructions and the site shows graceful placeholders until
those personal files are added. Add only media you have permission to share.

GITHUB PAGES
------------
See README.md for GitHub Pages publishing steps. Upload the extracted project contents, not the
ZIP file. This is a static HTML/CSS/JavaScript site and has no build step or dependencies.

ORIGINAL FILES
--------------
ORIGINAL_FILES contains byte-for-byte copies of the three files provided before the earlier
site enhancement. They are preserved for reference; edit the main files, not these backups.
